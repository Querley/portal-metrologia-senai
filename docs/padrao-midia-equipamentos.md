# Padrão de mídia dos equipamentos

Cada página de equipamento adota esta sequência:

1. imagem do equipamento isolado, em PNG com fundo branco sólido;
2. fotografia do mesmo equipamento instalado no Centro;
3. vídeo do equipamento em operação.

Uma posição só é publicada quando existir uma mídia correspondente e autorizada. Não usar ilustrações genéricas, simulações de software, fotos de instalações externas nem vídeos de outro modelo para completar a sequência.

## Recebimento futuro

- Guardar o original em `fontes/originais/midia/` e registrar nome, hash e autorização em `fontes/catalogo.md`.
- Criar uma cópia normalizada em `public/imagens/` apenas quando ela puder ser publicada.
- Identificar claramente equipamento, local, data aproximada, autoria e autorização de uso.
- Para vídeo, priorizar enquadramento horizontal, imagem estável, áudio dispensável e ausência de dados pessoais, telas confidenciais ou documentos visíveis.
- Manter legenda e texto alternativo factuais, sem afirmar capacidades que a mídia não demonstra.
